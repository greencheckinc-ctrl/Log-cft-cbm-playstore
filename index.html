Diagram & short description (Hoppus)
Round Timber Volume Calculator
Measurement Method: Hoppus (Quarter Girth Rule)

CBM Formula: CBM = (Girth × Girth × Length) ÷ 16
CFT Formula: CFT = CBM × 35.315

Units used:
• Girth: Meter (m)
• Length: Meter (m)
• CBM: Cubic Meter (m³)
• CFT: Cubic Feet (ft³)

Example: Girth = 0.39 m, Length = 2.30 m → CBM = 0.02186 m³, CFT = 0.7720 ft³

How to type:
• Length not set: write length + girth, e.g. 6063 or 60x63 (2.60 m, girth 63 cm).
• Length set above: write only the girth, e.g. 63.
• If Measurement unit is Meter, write girth in meters, e.g. 0.63.

Note: Volume is calculated using the Hoppus Quarter Girth method. Results may differ from actual cylindrical volume.
Diagram & short description (Sawn timber)
Sawn Timber Volume Calculator
Measurement Method: Width × Thickness × Length

CFT Formula: CFT = (Width × Thickness × Length) ÷ 144
CBM Formula: CBM = CFT ÷ 35.315

Units used:
• Width: Inch
• Thickness: Inch
• Length: Feet (the 2-digit code is feet + inch, e.g. 76 = 7 ft 6 in = 7.5 ft)
• CFT: Cubic Feet (ft³). The sheet shows CFT × 100

Example: Size 7x7-76 → 7 × 7 × 7.5 ÷ 144 = 2.552 CFT (the sheet shows 255)

Length rounding (default, Exact length not ticked): the length goes up to the next 3 inches (0.25 ft). A decimal is read as feet.inches, so 7.30 means 7 ft 3 in.
• 7.03 to 7.30 → 7.25
• 7.31 to 7.60 → 7.50
• 7.61 to 7.90 → 7.75
• 7.91 to 8.02 → 8.00 (a small .01 or .02 above a whole foot counts as that foot)
• Inch digit in a code: 1–3 → 3 in, 4–6 → 6 in, 7–9 → 9 in. So 73, 75 and 76 are 7 ft 3 in, 6 in and 6 in.

Exact length (tick box): when ticked there is no rounding. A decimal is plain decimal feet (7.24 stays 7.24 ft) and 75 is exactly 7 ft 5 in.

How to type:
• 7776, 7 7 76 or 7x7-76 all mean width 7, thickness 7, length 7 ft 6 in.
• Two-digit sizes: 101076 means 10 × 10, length 7 ft 6 in.
• Decimals work too, e.g. 7.5x6-76.

Note: The value is the real (square-edged) volume of the sawn piece.
Please tick if you need the exact length.
